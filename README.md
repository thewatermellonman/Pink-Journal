# Pink-Journal
This porject was made with html, css, and js.
I made it to explore cloning objects and having users resize them!

## Features
-Everything pink!!
-Cute stickers
-Text boxes

## Use
Click a sticker to add it to the page. The sticker resize bar changes the last sticker you've touched!

The add text button also adds text (WOAH). It can be resized by the lines in the corner of the box!
